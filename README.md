# My Risky Flying Game

## Overview:

This is a game where the player controls an aeroplane sprite, and must avoid running into too many clouds, whilst collecting (insert item to collect here later). The scoring of the game is determined by how fast the player can collect all collectable items. If the player runs into more than 3 clouds, then the game is over and there is no score returned. 

## Development process: 

Initially, I wanted to have a collision based game, using a vehicle of some kind to drive from one end of the canvas to another without hitting obstacles.
